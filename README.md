Snake Game
Классическая аркадная игра «Змейка», разработанная в рамках производственной практики по курсу ПМ.01 «Разработка модулей ПО для компьютерных систем». Это веб-приложение с двумя игровыми режимами, системой прогресса, таблицей рекордов и адаптивным дизайном для мобильных устройств.
Основные возможности

Функция	Описание
🎮 Два режима игры	Уровневый режим (шесть размеров поля: 6x6 до 21x21) и классика — бесконечный режим
📊 Система прогресса	Отслеживание заполнения игрового поля, открытие новых уровней
🏆 Таблица рекордов	Топ-10 результатов с сохранением в localStorage
⚡ Динамическая скорость	Скорость возрастает с каждым съеденным яблоком (регулируемый параметр)
📱 Мобильная адаптация	Сенсорные кнопки и поддержка управления на мобильных устройствах
🌓 Две цветовые темы	Возможность переключения между светлой и темной темой
🧪 Автотесты	Встроенная система тестирования ключевых функций
📝 Логирование	Запись игровых событий с экспортом в JSON
📦 PWA поддержка	Установка на устройства и работа оффлайн

Запуск

Онлайн

Откройте живую версию игры в любом современном браузере.
Локально

Клонируйте репозиторий:

git clone https://github.com/ZakharBlinov/Snake-Game.git
cd Snake-Game
Откройте файл snake.html в браузере (дважды кликните или перетащите файл).
Для PWA-функционала рекомендуется запускать локальный сервер:

npm install -g live-server
live-server
Установка на мобильное (PWA)

Android: Откройте сайт в Chrome → меню → «Добавить на главный экран».
iOS: Откройте сайт в Safari → «Поделиться» → «На экран “Домой”».
После установки игра работает оффлайн!
Управление и правила

Управление: клавиши стрелок на клавиатуре или экранные кнопки на мобильных.
Цель: собирать яблоки, избегать столкновений, заполнять поле (в режимах уровней).
Режимы:
🕹 Уровни: 6 сложностей с прогрессом и разблокировкой.
🎯 Классика: бесконечный режим с увеличением скорости и рекордами.

Обнаружение столкновений
Поедание яблок
Изменение направления
Границы игрового поля
Сохранение рекордов
Итоги отображаются в подробном отчёте.
